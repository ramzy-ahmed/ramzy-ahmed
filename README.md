- 📱 **Android:** Kotlin, Java, Android SDK, Jetpack Compose, Android Jetpack

- 🌐 **Web:** React, JavaScript, TypeScript, Tailwind CSS, Vite, HTML, CSS.
- 🧱 **Architecture:** MVVM, MVI, MVC, Clean Architecture, and OOP
